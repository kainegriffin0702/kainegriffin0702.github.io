# Overview

This project was completed as part of **MATH 4740**, Optimization and Data Analysis, and was based on research conducted by my professor, [Dr. Weiwei Hu](https://www.math.uga.edu/directory/people/weiwei-hu), on failure rate identification. I investigated a foundational problem in this area: the optimal control of a two-state reparable system. Using a gradient descent algorithm and adjoint-based optimization, I explored how a nonnegative control input \\(u(t)\\) can be used to guide the system's probabilities toward desired states, providing insight into the core challenges of this field.

**Skills Developed:**
- Optimal control theory
- Gradient descent optimization
- Adjoint method with Lagrange multipliers
- Numerical methods (backward Euler)
- Python programming with NumPy and Matplotlib
